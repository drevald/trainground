# trainground

A personal learning lab that replays the growth story of large-scale
systems (Amazon, Google, Instagram...) — building the same
architectural evolution and technologies step by step, phase by phase,
to learn system design and infrastructure hands-on.

## Structure
- `services/` — application code, one folder per service
- `k8s/` — Kubernetes manifests
- `experiments/` — side explorations (non-Amazon branches)
